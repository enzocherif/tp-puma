# TP Robot PUMA — SYSMER 2A (SeaTech)

Modélisation multicorps du bras robotique PUMA avec Simulink / Simscape Multibody.

- `pumacherif.slx` : modèle Simulink (R2023b)
- `stl/` : pièces 3D du robot (à garder dans ce dossier, le modèle les charge)
- `pumacherif.avi` : vidéo de la simulation
- `rapport/` : compte rendu (binôme Berta & Cherif)

Nécessite **Simscape Multibody**.
